# hide-and-seek

A tiny top-down hide-and-seek game for the browser. No dependencies, no build step.

## Run

Open `index.html` in a web browser.

## Play

- Move the blue dot with the arrow keys or WASD.
- The red seeker searches the map. Break line of sight by hiding behind the brown obstacles.
- If the seeker touches you, you lose. Survive 30 seconds to win.
- Click "Play again" (or press Enter) to restart.
