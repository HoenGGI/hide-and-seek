# 다같이 문으로!

친구들과 한 화면에서 같이 하는 협동 퍼즐 게임 (2~4명).
열쇠를 주워 문을 열고, **모두가** 문에 들어가면 스테이지 클리어!

## 실행 방법

`index.html` 을 브라우저(크롬 추천)로 열면 바로 실행돼요. 설치할 건 없습니다.

## 조작

| 플레이어 | 이동 | 점프 | 문 들어가기 |
|---|---|---|---|
| 1P | A / D | W | S |
| 2P | ← / → | ↑ | ↓ |
| 3P | J / L | I | K |
| 4P | 넘패드 4 / 6 | 넘패드 8 | 넘패드 5 |

- 게임패드를 연결하면 연결한 순서대로 1P, 2P ... 를 조작해요.
- `R` 스테이지 다시하기, `ESC` 메뉴로

## 규칙

- 친구 머리 위에 올라탈 수 있어요. 친구를 밟고 점프하면 더 높이 올라가요.
- 숫자가 적힌 버튼과 상자는 그 인원만큼 같이 올라가거나 밀어야 해요.
- 가시에 닿거나 떨어지면 시작 위치에서 다시 나와요.

## 스테이지 만들기

스테이지는 `js/levels.js` 에 글자로 그려져 있어요. 가로 30칸, 세로 17칸입니다.

| 기호 | 뜻 |
|---|---|
| `#` | 벽 / 바닥 |
| `P` | 시작 위치 |
| `*` | 열쇠 |
| `@` | 문 (이 칸 위로 2칸 높이) |
| `^` | 가시 |
| `a` `b` `c` | 버튼 |
| `A` `B` `C` | 같은 글자 버튼으로 열리는 벽 |
| `X` | 상자 (크기·무게는 `boxes` 에서 설정) |
| `=` | 움직이는 발판 (이동 거리·버튼은 `platforms` 에서 설정) |

- 혼자 점프: 약 2칸 높이까지
- 친구를 밟고 점프: 3칸 높이까지
- 버튼 `req`, 상자 `weight` 에 `'all'` 을 쓰면 "플레이어 전원" 이라는 뜻이에요.
