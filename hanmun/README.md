# 오티링고 — 과목별 학습 앱

국어 · 역사 · 한문 · 과학을 듀오링고처럼 매일 조금씩 공부하는 앱이에요.
지금은 2학년 2학기 **한문**(학습지와 공책 정리: 14과 삶을 이끈 한마디, 15과 할아버지와 걷는 눈길, 김만덕 이야기 등)과
**역사**(개념 학습지 9장: 영국·미국·프랑스 혁명, 라틴 아메리카, 산업 혁명, 제국주의, 두 차례 세계 대전, 러시아 혁명, 대공황)가 들어 있어요.
하트 없이 몇 번 틀려도 레슨을 끝까지 할 수 있어요.

- **설치**: `otilingo.apk`를 안드로이드 휴대폰에 받아 설치 (출처를 알 수 없는 앱 설치 허용 필요)
- **웹**: 이 폴더의 `index.html`을 열면 브라우저에서도 똑같이 쓸 수 있어요

문제 종류: 훈음 고르기, 한자 고르기, 짝 맞추기, 독음 고르기/쓰기, 뜻 고르기, 빈칸 채우기,
문장 풀이 배열, 독음 배열, 한자 배열, **풀이 순서대로 누르기**, 듣고 고르기(앱에서), 개념 문제.
틀린 문제는 레슨 끝에 다시 나오고 **복습 → 오답 노트**에 모여요.

- **퀴즈 탭**: 범위(전체 또는 단원)와 10·20·30문제를 골라 시험처럼 풀고 마지막에 한꺼번에 채점해요.
  학교 시험 형식으로 직접 만든 문제(단원마다 20개: 한문 100개, 역사 80개)에 자동 문제를 섞어 내요.
  점수, 문제별 내 답·정답·해설, 틀린 문제 다시 풀기, 최근 기록이 있어요.
- **모의고사**: 퀴즈 탭 맨 위. 학교 시험처럼 정해진 20문항(객관식 16 + 단답형 4, 문항당 5점)을 45분 타이머로 풀어요.
  역사 1~3차(`HISTORY_MOCK`), 한문 1~3차(`MOCK`). 시간이 다 되면 남은 문제는 틀린 것으로 채점하고, 회차별 최고 점수가 남아요.
- **친구와 대결**: 퀴즈 탭 맨 위. 카훗처럼 방장이 방을 열면 여섯 자리 방 번호가 나오고, 친구들은 각자 휴대폰에서
  그 번호와 별명을 넣고 들어와요. 모두 같은 객관식 문제를 동시에 풀고, 빨리 맞힐수록 점수가 높아요(500~1000점, 연속 정답 보너스).
  문제마다 정답과 순위를 보여 주고, 끝나면 1~3등 시상대가 나와요. 범위, 5·10·15·20문제, 문제당 10·20·30초를 골라요.
  인터넷이 필요해요. 휴대폰끼리는 공개 MQTT 중계 서버(`battle.js`의 `MQ_BROKERS`, 방 번호 첫 자리가 서버 번호)를 거쳐
  별명 · 문제 번호 · 고른 답 · 점수만 주고받고, 문제 내용은 각자 앱에 있는 것을 보여 줘요. 그래서 모두 같은 버전 앱을 쓰는 게 좋아요.
  **초대 링크**: 대기실의 '초대 링크 보내기'(휴대폰 공유 창) 또는 '링크 복사'. 링크는 `https://messioftft.netlify.app/?join=방번호`
  (웹으로 올린 주소에서 열면 그 주소)이고, 누르면 방 번호가 들어간 참가 화면이 열려요. 앱은 `otilingo://join/방번호`로도 열려요.
  웹 주소를 바꾸면 `battle.js`의 `INVITE_BASE`를 고쳐요.
- **요약 탭**: 단원마다 핵심 어휘 표, 문장(독음·풀이), 꼭 알아 둘 글자, 시험 포인트를 한 장으로 정리했어요.
  "답 가리기"를 켜면 독음과 뜻을 가리고 눌러서 확인할 수 있어요. "전체 노트"에서는 모든 내용을 검색해요.

- **틀렸을 때**: 고른 보기에 "내 답", 맞는 보기에 "정답" 표시가 붙고, 아래에 내 답과 그 답이 실제로 무엇인지
  (다른 한자의 훈음, 다른 어휘의 뜻, 다른 책·인물 설명 등)를 함께 보여 줘요. 퀴즈 채점 화면도 같아요.
- **건너뛰기**: 모르는 문제는 "건너뛰기"로 넘기면 정답을 보여 줘요.
  그 문제는 레슨 끝에 다시 나오며 오답 노트에도 들어가요. 퀴즈에서는 건너뛴 문제가 오답으로 채점돼요.
- **시험 안내**: 학습 화면 맨 위 D-day 카드를 누르면 2학년 2학기 2차시험 시간표(날짜·교시·입실 시간)와
  과목별 시험 범위가 나와요. 다음 시험 때는 `exams.js`만 고치면 돼요.
- **과목 탭**: 위쪽에 국어 · 역사 · 한문 · 과학 탭이 있어요. 지금은 한문만 내용이 있고
  나머지는 "준비 중" 화면이에요. 과목 이름·순서·색은 `subjects.js`에서 바꿔요.
  다른 과목에 내용을 넣을 때는 `ready: true`로 바꾸고 그 과목의 레슨 데이터를 추가해야 해요.
  (지금 문제 엔진은 한문 기준이라, 과목에 맞는 문제 형식도 함께 만들어야 해요.)

## 국어 내용

`korean.js`에 2학년 2학기 국어 학습지(본학습 활동지·소단원 지필 평가) 내용을 옮겼어요.

| 단원 | 내용 |
|---|---|
| 1단원 국어의 음운과 문자 (3-(1)) | 음운의 개념과 종류, 소리의 길이, 단모음·이중 모음과 단모음 체계, 자음 체계(위치·방법·세기), 훈민정음 창제 정신과 원리, 한글의 특성과 가치 |
| 2단원 듣기·말하기 성찰하기 (3-(2)) | 말하기 불안과 원인·해소, 점검과 조정, 김윤서의 토론회, 성찰 일지 |
| 3단원 복합양식 평가하며 읽기 (4-(1)) | 복합양식, 〈반려동물은 가족이자 친구〉, 타당성·신뢰성·적절성, 노로바이러스 보도 |
| 마무리 | 종합 평가 ①② · 헷갈리는 것 총정리 · 최종 평가 ①② |

문제 은행(`KOREAN_EXAM`) 단원마다 20개, 모의고사(`KOREAN_MOCK`) 1·2차.

## 역사 내용

`history.js`에 정리 카드(N), 단원·레슨(HISTORY_UNITS), 핵심 요약, 시험 형식 문제가 있어요.
레슨 문제 형식: 객관식, 보기 상자 문제(ㄱ·ㄴ·ㄷ·ㄹ), 단답형 쓰기, 사건 순서 맞추기, 용어 짝 맞추기, 용어 뜻 고르기, O/X.
'우리 해 보자' 단원(h5)에는 교과서 자료 탐구 6개(미국 독립 선언문·헌법, 프랑스 혁명의 의의, 영국의 선거권 확대, 「백인의 짐」, 베르사유 조약, 전체주의 국가의 주장)가 자료를 읽고 답하는 문제로 들어 있어요.

```js
{ q: '1774년 식민지 대표들이 모여 영국에 항의한 회의는?', a: '대륙 회의', w: ['삼부회', '국민 의회', '베를린 회의'] },
{ t: 'short', q: '차 상자를 바다에 던진 사건은?', a: ['보스턴 차 사건'] },
{ t: 'seq', q: '일어난 순서대로 나열하세요', a: ['국민 의회', '입법 의회', '국민 공회', '총재 정부'] },
```

새 과목을 넣을 때는 같은 형식의 파일을 만들고 `subjects.js`에서 그 과목에 `data`를 연결하면 돼요.

## 내용 고치기 · 추가하기

`data.js`만 고치면 돼요.

```js
W('觀衆', '관중', ['볼 관', '무리 중'], '운동 경기 등을 보기 위해 모인 사람들', { ex: '○들과 함께…' });
Sen('gu', '苟日新이어든', ['진실로 구', '날 일', '새 신'], '진실로 어느 하루 새로워졌거든');
```

요약은 `SUMMARY`, 퀴즈 문제는 `EXAM`에 단원별로 적어요.

```js
{ q: '夕陽의 뜻으로 알맞은 것은?', a: '저녁때의 저무는 해', w: ['아침에 떠오르는 해', '한낮의 뜨거운 볕', '밤하늘의 밝은 달'] },
{ t: 'short', q: '다음 어휘의 독음을 쓰시오.', p: '往來', a: ['왕래'] },
```

그다음 아래 순서로 다시 만들어요.

```sh
python3 tools/make_font.py          # 새 한자를 글꼴에 넣기 (fonttools, fonts-noto-cjk 필요)
cd ../apk_hanmun && ./gradlew assembleRelease
cp app/build/outputs/apk/release/otilingo-release.apk ../hanmun/otilingo.apk
```

브라우저 개발자 도구에서 `__ilsin.validate()`를 실행하면 훈음 개수, 독음, 풀이 순서가 맞는지 점검해 줘요.

## 알아 둘 점

- 기록(XP, 연속 학습, 오답 노트)은 휴대폰 안에만 저장돼요. 앱을 지우거나 서명이 다른 새 APK로 바꾸기 전에는
  **프로필 → 백업 코드 복사**로 기록을 옮겨 두세요.
- APK는 개발용 키로 서명돼 있어요. 다른 컴퓨터에서 다시 빌드하면 서명이 달라져서 기존 앱을 지우고 설치해야 해요.
